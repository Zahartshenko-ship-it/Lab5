# Казанцев Захар Лаб-2(ИТ-5,6) Лабораторная №5 (Вариант 4)

# Постановка задачи

Разработать консольное приложение на языке C# с дружественным пользовательским интерфейсом для работы с базой данных «Автопарк» из файла Microsoft Excel (`LR5-var4.xls`).

**Функциональные требования:**

1. Чтение базы данных из Excel-файла (`LR5-var4.xls`).

2. Просмотр содержимого таблиц базы данных.

3. Удаление элементов (по первичному ключу `ID`).

4. Добавление новых элементов с проверкой корректности данных.

5. Реализация 4 запросов с помощью LINQ:

   * 1 запрос с обращением к одной таблице (возвращает перечень);

   * 1 запрос с обращением к двум таблицам (возвращает одно значение);

   * 2 запроса с обращением к трём таблицам (один возвращает перечень, второй — одно значение).

6. Сохранение внесённых изменений обратно в Excel-файл.

7. Обработка возможных ошибок при вводе данных и чтении файла.

**Описание предметной области (Вариант 4):**

База данных «Автопарк» состоит из трёх связанных таблиц:

* **«Автомобили»** (`ID` — первичный ключ, `Марка`, `Модель`, `Год выпуска`).

* **«Водители»** (`ID` — первичный ключ, `Имя`, `Возраст`, `Стаж вождения`).

* **«Рейсы»** (`ID` — первичный ключ, `ID автомобиля` — внешний ключ к таблице «Автомобили», `ID водителя` — внешний ключ к таблице «Водители», `Дата начала рейса`, `Дата окончания рейса`, `Расстояние`, `Стоимость`).

# Описание классов и алгоритмов решения

## Модели данных (`Car`, `Driver`, `Trip`)

Для представления записей каждой таблицы реализованы отдельные классы, содержащие закрытые поля, свойства с валидацией, конструкторы (по умолчанию и с параметрами) и переопределённый метод `ToString()`:

* **Класс `Car`** (`Car.cs`):

  * *Свойства:* `Id` (`int`), `Brand` (`string`), `Model` (`string`), `Year` (`int`).

  * *Конструкторы:* `Car()`, `Car(int id, string brand, string model, int year)`.

  * *Валидация и вывод:* проверяет непустые значения марки и модели, а также допустимый диапазон года выпуска (от 1886 до 2026). Метод `ToString()` возвращает строку вида `[Id] Brand Model (Year)`.

* **Класс `Driver`** (`Driver.cs`):

  * *Свойства:* `Id` (`int`), `Name` (`string`), `Age` (`int`), `Exp` (`int`).

  * *Конструкторы:* `Driver()`, `Driver(int id, string name, int age, int exp)`.

  * *Валидация и вывод:* контролирует непустое имя, возраст в пределах от 18 до 120 лет и корректность стажа вождения (от 0 до значения `Age - 18`). Метод `ToString()` форматирует запись в виде `[Id] Name | Возраст: Age | Стаж: Exp лет`.

* **Класс `Trip`** (`Trip.cs`):

  * *Свойства:* `TripId` (`int`), `CarId` (`int`), `DriverId` (`int`), `StartDate` (`string`), `EndDate` (`string`), `Distance` (`int`), `Price` (`string`).

  * *Конструкторы:* `Trip()`, `Trip(int tripId, int carId, int driverId, string startDate, string endDate, int distance, string price)`.

  * *Валидация и вывод:* проверяет заполненность дат начала и окончания рейса, стоимости, а также неотрицательность расстояния (`Distance >= 0`). Метод `ToString()` выводит сводную информацию о рейсе.

## Чтение и запись Excel (`ExcelReader`, `ExcelWriter`)

Работа с файлом формата `.xls` реализована с использованием библиотеки `NPOI`:

* **Класс `ExcelReader`** (`ExcelReader.cs`):

  * `OpenWorkbook(string path)` — открывает файловый поток и загружает книгу `HSSFWorkbook`.

  * `ReadCars`, `ReadDrivers`, `ReadTrips` — построчно считывают листы книги (`GetSheetAt(0..2)`), извлекают значения ячеек через вспомогательные методы `ReadInt` и `ReadText` и заполняют коллекции `List<Car>`, `List<Driver>`, `List<Trip>`. Обработка исключений `try / catch` внутри цикла позволяет корректно пропускать повреждённые строки без аварийного завершения программы.

* **Класс `ExcelWriter`** (`ExcelWriter.cs`):

  * `SaveWorkbook(...)` — формирует новую книгу `HSSFWorkbook`, создаёт листы «Автомобили», «Водители» и «Рейсы» с заголовками столбцов, записывает актуальные данные из списков и сохраняет файл на диск.

## Вспомогательный класс бизнес-логики (`FleetService`)

Вся работа с коллекциями и запросами сосредоточена в классе `FleetService` (`FleetService.cs`):

* **Управление данными:**

  * `PrintCars()`, `PrintDrivers()`, `PrintTrips()` — вывод элементов соответствующих таблиц в консоль.

  * `AddCar`, `AddDriver`, `AddTrip` — добавление новых объектов с проверкой уникальности первичного ключа (и проверкой существования внешних ключей `CarId` и `DriverId` при добавлении рейса).

  * `RemoveCarById`, `RemoveDriverById`, `RemoveTripById` — поиск записи по ключу через `FirstOrDefault` и её удаление.

  * `GetNextCarId()` — автоматический расчёт следующего свободного `ID` для нового автомобиля.

* **Формулировки и реализация LINQ-запросов:**

  1. **Запрос к 1 таблице (перечень):**

     * *Формулировка:* Получить перечень всех автомобилей, выпущенных начиная с заданного года (`minYear = 2022`), отсортированный по марке и модели в алфавитном порядке.

     * *Реализация (`GetCarsFromYear`):* фильтрация коллекции `Cars` оператором `where car.Year >= minYear` с последующей сортировкой `orderby car.Brand, car.Model`.

  2. **Запрос к 2 таблицам (одно значение):**

     * *Формулировка:* Определить суммарный пробег (в километрах) по всем рейсам, выполненным на автомобилях заданной марки (`brand = "Opel"`).

     * *Реализация (`GetTotalDistanceByBrand`):* соединение таблиц `Trips` и `Cars` (`join car in Cars on trip.CarId equals car.Id`), фильтрация по марке без учёта регистра и агрегация методом `Sum()`.

  3. **Запрос к 3 таблицам (перечень):**

     * *Формулировка:* Получить перечень рейсов (с указанием номера рейса, имени водителя, марки и модели автомобиля, а также дистанции), совершённых водителями со стажем вождения не менее `8` лет на автомобилях не старше `2020` года выпуска.

     * *Реализация (`GetTripsByExpAndYear`):* последовательное соединение таблиц `Trips`, `Drivers` и `Cars` по ключам `DriverId` и `CarId`, фильтрация по условию `driver.Exp >= minExp && car.Year >= minYear` и проекция в форматированные строки.

  4. **Запрос к 3 таблицам (одно значение):**

     * *Формулировка:* Подсчитать общее количество рейсов, выполненных водителями в возрасте от `45` лет и старше на автомобилях марки `"Opel"`.

     * *Реализация (`CountTripsByDriverAgeAndBrand`):* объединение всех трёх таблиц (`Trips`, `Drivers`, `Cars`), отбор записей по возрасту водителя и марке автомобиля с подсчётом количества методом `Count()`.

## Пользовательский интерфейс (`Program`)

В классе `Program` (`Program.cs`) реализовано циклическое консольное меню, позволяющее пользователю выбирать действия (`1` — просмотр базы, `2` — добавление автомобиля, `3` — удаление автомобиля по `ID` с подсказкой диапазона доступных идентификаторов, `4` — выполнение всех четырёх LINQ-запросов, `5` — сохранение изменений в Excel, `0` — выход). Все операции пользовательского ввода защищены проверками `int.TryParse` и блоками `try / catch`.
